# EASY CODE — منصة تعلم برمجة عربية
موقع ويب + PWA (يتثبت على الأندرويد) بيعلّم HTML و CSS و JavaScript بالعربي، ومعه محرر تجريبي مباشر.

## المحتوى
1. 3 مسارات (HTML, CSS, JavaScript) و15 درس
2. محرر تجريبي: تعديل الكود ومشاهدة النتيجة لحظيًا
3. بحث داخل الدروس
4. حفظ التقدم محليًا (localStorage)
5. وضع ليلي/نهاري
6. يعمل أوفلاين بعد أول زيارة (Service Worker)

## التشغيل محليًا
افتح index.html في المتصفح، أو شغّل:
python3 -m http.server 8080
ثم افتح http://localhost:8080
